Roboto (Regular, Medium, Bold), the typeface the official Sphinx apps use,
copied from `sphinx-mac-v2/com.stakwork.sphinx.desktop/Fonts`. Roboto is by

`scripts/run-app.sh` copies the font files into the app bundle;
`ATSApplicationFontsPath` in its Info.plist registers them.
